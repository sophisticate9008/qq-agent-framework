# 随附的中文字体

`wqy-microhei.ttc` 是未经修改的文泉驿微米黑 0.2.0-beta 字体集合，包含 WenQuanYi Micro Hei 和 WenQuanYi Micro Hei Mono 常规字体，支持中日韩及拉丁文字。渲染器直接加载本地字体，无需安装系统字体或发起网络字体请求。
