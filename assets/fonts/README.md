# Bundled Chinese font

`wqy-microhei.ttc` is the unmodified WenQuanYi Micro Hei 0.2.0-beta font collection. It contains the regular `WenQuanYi Micro Hei` and `WenQuanYi Micro Hei Mono` families and supports Chinese, Japanese, Korean and Latin text. The renderer loads this local asset; no system font installation or network font request is required.
