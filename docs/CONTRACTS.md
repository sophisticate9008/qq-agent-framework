# 公共契约与修改约束

公共接口的类型和校验集中在 [src/contracts](../src/contracts)、[src/core](../src/core) 与 SDK 导出。HTTP、协议响应和持久文件均在边界校验；TypeScript 类型不能替代运行时解码。扩展 API 用法见 [扩展开发](EXTENDING.md)，操作恢复见 [恢复手册](RECOVERY.md)。

## 身份、范围与权限

人设、配置、偏好、运行状态、资源、权限独立建模。正文、昵称、引用、转发和模型输出均不能授予主人身份。主人由配置中的真实账号确定；工具审批只认所属 QQ 会话中该账号的实际答复。管理员网页登录权限不构成模型工具批准。

会话键使用 `group:<id>` 或 `private:<id>`，并受协议和账号边界约束。入站的身份与授权上下文由宿主建立，输入转换不得覆盖。媒体、引用、记忆、工作结果均核验来源与可见范围；声明为全局共享的记忆仍属于同一账号。

能力状态分别描述声明、安装、就绪和授权。未知授权使用明确的未知值，不能转换为允许。功能开关只控制参与范围，不扩大访问策略；发送、工作、媒体、工具和定时触发在实际副作用前核验当前权限。DSH 自有工具权限由 DSH 管理，框架只投影自身的受控工具与服务。

## 配置与操作版本

原生配置 revision schema 为 `1`，包含 `plans`、`personas`、`access`、`adapters`、`providers`、`authorization`、`deployment`、`execution` 八个键，各为 64 位小写十六进制摘要。见 [native-revisions.ts](../src/contracts/native-revisions.ts)。包配置、包状态与会话绑定另有各自版本；目录 revision 不能代替 bindingRevision。

写操作使用明确的期望版本和 CAS。无关目录编辑不应阻断当前聊天；当前选中的定义、主人、工具或部署依赖改变时必须重新核验。保存成功、部署已应用、运行中快照是不同状态。

应用编排保留持久 operationId，按停止、准备、应用、迁移、启动阶段记录结果。网络失败不等于操作失败：未知结果应查询原 operationId，不自动提交第二次副作用。兼容模型、推理与容量迁移使用单次检查点 fork 和 SDK 读回，保留原历史；未知 fork 不再创建第二份会话。

方案页的一次更新先以 CAS 保存并启用当前编辑方案，再携带该保存回包的实际 revision 创建唯一应用；它不隐式保存其他配置域。保存失败时不提交应用，明确未受理的拒绝不等于外部结果未知。慢操作只观察同一 operationId。

应用阶段的 `pending_reload` 有界等待实际 DSH 加载核验；确认写入但未及时加载可转为 blocked。显式 application reconcile 在原 apply 阶段证据齐全、原配置版本仍匹配时，可沿同一 operationId 继续 migrate/start；它跳过 stop/prepare/apply，不重新应用。GET 保持纯观察，其他未知阶段不能据此推测或重放。

## 执行与恢复

`accepted` 只表示请求已接受，不能代表执行完成或消息已送达。每个执行保留父会话、账号、generation 与回执关联。只有证实的终态才能结算；超时、断线、取消未确认和迟到终态各有独立语义。

当前原生运行状态中的 `modelExecutionVerified: false` 固定表示启动检查只核对连接与配置，不发送模型请求；它不是等待后台补齐的调用成功记录，也不是尚未完成的用户任务。实际请求、回复和失败通过对应会话与执行记录核对。

默认主聊天总期限为 **120000ms**；取消与通知期限各 **5000ms**。默认取消开启、超时通知关闭、未知执行隔离会话、迟到终态仅记账，最大活动执行数为 256。独立出站网关请求默认期限 **60000ms**，它不是主聊天总期限。见 [native-execution.ts](../src/host/native-execution.ts)、[settings.ts](../src/admin/settings.ts)。

未知执行不自动重放，不因清统计、切页或重启变成完成。恢复需要可核验证据；明确建立新地址后仍保留旧执行风险。手动重置只建立新的聊天上下文，保留历史，不能宣称停止了外部工作。关闭流程分别排空资源；未确认停止的租约与存储不应被提前释放。

## 输入、输出与事件

输入上下文区分可信事实与不可信内容，记录预算截断和缺失。媒体 assetId 只证明已登记，实际读取另有回执。远程协议返回错误范围的引用属于无效响应，不能把正文交给模型。宿主直接检查越界引用时也必须拒绝，具体错误分类按所在边界返回。

模型参与使用 `qaf.reply/1`，结构化静默由宿主消费；输出使用 `qaf.output/1`。内部控制结构不发送给 QQ 用户。普通正文、代码和媒体按实际输出策略处理；未知发送不自动重发。外发媒体需要已验证的实际资源，不接受任意 URL 或本机路径来绕过资源边界。

`qaf.events/1` 事件接口提供关联标识和状态元数据，支持过滤、分页、有界背压、取消及 epoch 缺口。事件流不承载私有正文；流断开后的缺口不能被解释为“没有发生操作”。

## 包与账号

包 manifest 检查依赖、重名、循环和服务版本。输入 prepare、context provider、限制性 guard 与只读 observe 各司其职；确定排序、预算、期限与失败策略。定时器、订阅、服务和任务都有包归属，依赖顺序启动、逆序停止，回滚只处理本次安装资源。

状态使用稳定包键和 schemaVersion，通过可恢复 CAS 与分页迁移演进。旧状态必须明确接管。内容指纹声明覆盖的文件、依赖和锁文件；entry-only 指纹不能冒充完整包内容身份。内容改变需要重新核验，进程内 ESM 缓存不能当作热更新保证。

协议工厂 `NativeAccountProtocol.create` 同步返回运行对象，异步工作放在 `start(signal)`。错误返回的 thenable 会被拒绝，不能隐式 await 或自动重试。账号注册上限 32，OneBot accountId 使用规范的 1–32 位数字，账号注册 ID 为 64 位小写十六进制摘要。

账号管理入口为 `/api/accounts`。账号内管理请求通过 `/api/accounts/dispatch?account=<注册ID>&path=<编码后的已注册路由>` 分发，仅允许明确登记的 GET/POST 路由；它不是任意代理。旧数据显式接管后，旧全局路由返回冲突，调用方须选择账号。各账号持有独立配置、数据库、策略、资源和 DSH 命名空间。

## 读写与可观测性

普通历史、统计与状态读取不能创建业务数据库、配置或发送动作。SQLite 读取仍可能进行 WAL/SHM 协调。**迁移 GET 预览会持久化 prepared plan**，因此不能笼统承诺所有 GET 都零写入；具体接口以领域契约为准。

用量未知值保持未知，多币种分别汇总，历史记录不按后来价目表重算。维护操作有预览、CAS、operationId 和记录；清理统计不能删除未结执行证据。前端只读缓存按 API 身份与账号隔离，退出清理，取消后旧回包不能覆盖新状态；缓存不提供权限依据。

公共 API、命令、默认值或恢复语义变化时，同步更新调用方、对应测试和公开文档。不得依赖文档中的旧实现行号或历史审计结论改变当前契约。
