# 管理工作台

工作台管理本框架自己的配置与资源。它不需要其他桥接项目，不读取其配置，也不调用其控制台。

## 初始化与启动

```sh
npm ci
npm run cli -- init
npm start
```

`init` 只执行一次。它创建私有管理配置、网关配置与网关令牌，已有文件存在时拒绝覆盖；目录为 `0700`、文件为 `0600`，令牌不回显。管理配置路径依次选择 `--config`、`QQ_AGENT_CONFIG`、`runtime/admin/config.json`。

默认界面为 `http://127.0.0.1:3210/`。需要允许局域网访问时：

```sh
npm run cli -- init --host 0.0.0.0 --port 3210
npm start
```

已有配置也可以在“运行设置”修改监听地址。浏览器应使用机器实际地址，而不是访问 `0.0.0.0`。前端始终使用同源相对 API，不写死 IP 或端口。

只启动管理 UI/API：`npm run cli -- start --admin-only`。管理服务同时提供静态前端，无需另开前端命令。

## 首次登录

首次网页访问生成随机私有管理员令牌文件，登录窗口显示文件位置，不返回令牌值。用户在本机读取后登录；后端签发独立访问会话。表单随后立即清空，管理员令牌不写入浏览器存储、cookie、URL 或日志。

访问会话采用同源 `HttpOnly`、`SameSite=Strict`、`Path=/api` cookie。普通 API 请求使用访问会话，不重复发送管理员令牌。刷新通过 `GET /api/auth/session` 恢复；主动退出调用 `POST /api/auth/logout`，立即撤销会话。

默认有效期七天，可在运行设置中调整，范围五分钟至三十天；有效期是绝对期限。管理服务重启会使已有访问会话失效，但不更换管理员凭据。

管理员令牌、管理访问会话与 OneBot/DSH 的协议凭据分别管理，不能互换。

## 聊天方案与人设

侧栏“聊天方案”直接管理本框架自有的方案库。方案保存名称、行为指令、模型路由与所关联的人设标识；人设库独立保存身份和表达风格。

保存使用 revision 条件写入。其他窗口更新后，旧草稿保存会冲突；操作结果未知时先重新读取，不自动重试。方案与人设正文不会进入全局搜索。

选择方案只是保存本框架希望使用的编排，不安装外部 DSH 插件、不扩大权限、不自动清空或替换已有会话。原生宿主未装配时，界面必须明确说明保存与实际运行尚未接通。

人设不包含工具权限；访问策略、功能授权、偏好和运行状态分别建模。功能源码存在不等于已装配运行，更不等于已获得副作用权限。

## 网关与访问范围

侧栏“适配器”集中配置 OneBot HTTP、可选 webhook 和 DSH。默认全部关闭；凭据只写入服务端私有文档，不回显原值。留空保留，明确选择清除才删除。保存只是记录连接参数，不会调用模型、发消息或启动监听；未装配原生宿主时，页面如实显示未装配并禁用启动按钮。开发接线和契约见 [适配器配置](ADAPTERS.md)。

网关默认监听回环 `127.0.0.1:3131`，OneBot upstream 默认 `http://127.0.0.1:3000`。协议服务由使用者部署并认证。请求默认期限 60 秒。

允许发送范围默认空，拒绝全部带目标的发送。按实际需要填写 `group:群号` 或 `private:QQ号`；预算关闭不绕过允许范围、协议认证或 capability 授权。

预算开关和数值独立保存，关闭后保留原数值，再开启恢复使用。保存与重启应用分开；管理端只允许应用本框架的管理/网关组件，不操作其他桥接服务。

## 会话与用量

会话和用量只读取显式装配的原生宿主/账本，不代理外部桥接控制台。未装配时返回“聊天宿主尚未接入”，而不是空会话、零用量或演示成功。

用量页保留累计分类、走势、会话与逐轮、最近调用和价目等展示能力；图表使用 Recharts。默认计数按 k/m/b 精简，标题旁“详细数值”仅影响该页，不写全局配置、不改原始值、金额或百分比。

逐轮与最近调用均可折叠，展开后内容固定高度，表格内部纵横滚动、表头固定。输入/输出用上下箭头，缓存图标后直接接命中数值；未命中、写入与推理不再多占明细行，可在悬浮说明和累计分类核对。

数据源未接通不提供破坏性 reset。宿主以后接入 reset 时必须提供 revision 条件删除、危险确认和明确的未知结果语义，不得用保存成功冒充磁盘截断或外部任务已停止。

## 扩展与验证

页面使用共享 Section、Field、SaveBar、主题和目录/搜索范式。具体业务包 UI 由业务方显式编写、审核、构建和装配；不会从聊天内容或任意路径动态执行代码。

普通用户不需要安装测试浏览器。`npm run test:browser` 会按需准备隔离回归环境，不应对真实 QQ、模型或生产会话执行测试写入。更多见 [UI 范式](UI.md)、[扩展](EXTENDING.md)与 [OneBot 网关](ONEBOT_GATEWAY.md)。
