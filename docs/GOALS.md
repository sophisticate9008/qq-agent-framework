# 目标与产品边界

本文描述当前框架的持续目标。实现事实以源码、公共契约和测试为准；本轮的 [80 项清单](IMPROVEMENT_CHECKLIST_2026-10-25.md) 是交付记录，后续需求应另行明确。

## 会话体验

日常聊天与明确工作请求共用连续语境。输入包含可信发言者与会话事实、唤醒原因、引用、媒体句柄及有界未读；普通忙碌期间接收追加与纠正，结果未知时按执行风险隔离。直接呼叫、昵称、引用机器人和短时续聊进入参与判断，别人互聊或话题结束时允许结构化静默。

媒体登记、实际读取和理解分别记录。图片需要模型实际接收图像，音频依赖可用的转写服务，文件读取受格式、大小和会话可见性约束。能力缺失时准确说明，不把占位符当作内容。输出支持分气泡、媒体与长文转发，但最终行为由当前授权、输出配置和真实发送回执决定。

主人可以委派真实后台工作，聊天继续进行；工作支持追加、状态、停止、子任务提问和结果回传。模型提问和工具同意、拒绝只接受所属 QQ 会话中实际配置主人的答复。网页提供只读状态与明确的配置、维护操作。

记忆和偏好具有来源、范围、确认状态和有效期；模型推测不会自动成为确认偏好。提醒按明确规则触发，并再次核验当前权限。定时主动找话题、黑话学习和默认语音偏好保持关闭；正常唤醒、工作回传和显式提醒各自实现。

## 框架扩展

扩展通过版本化 SDK、功能包、宿主服务、输入准备与上下文贡献、工具注册、日历任务和生命周期接入。协议、模型、存储和外部副作用通过适配器与受控宿主服务提供。新增业务优先扩展贡献和领域服务，避免复制一套连接、鉴权、交互与恢复逻辑。

包拥有自己的配置、状态与运行资源。安装不授予权限，配置不伪造运行状态，人设不增加能力。内容指纹、依赖检查、配置影响、状态迁移和停止排空都有可核验结果。可信本机 TypeScript 扩展在宿主进程内运行，因此 SDK 的能力边界不是任意恶意代码的安全沙箱。

协议与账号身份贯穿会话、策略、资源、幂等键和 outbox。同名 QQ 会话在不同账号下保持隔离。旧数据采用明确身份凭据与 CAS 迁移，不通过猜测归属自动合并。

## 控制台与维护

页面围绕用户任务组织，基础配置集中，低频技术参数放入高级区域。未接通的功能必须补齐实现或准确显示条件；不能通过删除入口掩盖能力缺口。导航、搜索、标题和别名来自统一注册表，折叠与切页保留草稿。

保存、应用和运行中版本分别呈现。操作结果未知时锁住危险重试入口，保留 operationId 并查询同一操作的证据。重置会话、兼容迁移和未知执行恢复是三种不同操作，不能互相替代。

使用 TypeScript strict、公共契约解码、依赖边界检查和实际入口测试维护结构。性能改进需要测量依据；单元测试、协议集成、真实时限、浏览器以及真实模型质量分别记录，不能相互冒充。当前已验证范围和限制见 [验收记录](VALIDATION.md)。
