1. 明确任务存储/出站恢复协议：accepted、running、unknown、confirmed、failed，不把重新执行当恢复。
2. 建立资源与产物服务：固定人设参考、审核记录、版本适配、有限重试、过期与清理规则。
3. 给工作 agent 独立工程入口：认证主人请求、结构化目标、可写范围、预算、测试、产物和装配权限。
