# 插件能力与统一会话服务设计

状态：2026-10-28 实施。交付范围见文末；源码为实现事实来源。

## 目标

日常聊天直接获得常用工具；冷门协议能力通过目录按需读取参数，再经统一入口执行。可信本机插件直接调用内部服务，不必经过模型目录，不依赖一条虚构的 QQ 主人消息。调用入口负责权限，能力实现负责参数、协议、资源和结果。

插件可以使用已配置的供应商和模型进行生成，也可以绑定现有会话或自动创建自己的持久会话。QQ、插件和助手共享会话管理基础设施，不各自维护无法管理的隐式绑定。

## 权限与工具分层

| 权限 | 行为 |
| --- | --- |
| 全部 | 白名单会话成员可触发，AI 也可按语境使用 |
| 主人或自主 | 主人可直接要求，AI 自行决定；不附加逐次审批、预登记任务或自身创建记录限制 |
| 主人 | 在聊天、命令或助手入口校验真实账号及授权来源 |

QQ 收藏表情的查询、收藏、删除、描述修改均为全部。消息贴表情、发送消息、媒体读取、会话内查询、戳一戳为全部。自身群名片、自身消息撤回、空间发布与删除允许主人或自主。未另行分类的账号管理、好友、群管理、文件管理和协议运维能力默认主人。

日常直接投影消息发送、媒体读取、会话查询、消息贴表情、收藏表情、自身群名片、戳一戳、撤回自身消息和助手入口。能力目录先显示分类摘要；查询具体工具才返回完整输入说明。执行入口按已登记的工具标识路由，不接受任意 URL、任意未登记协议动作或模型声明的调用者身份。

可信插件由宿主加载和提供身份；命令插件负责检查真实命令发言者，定时任务继承插件身份。可信插件内部调用不额外要求 QQ 会话白名单或主人消息。插件生命周期结束后不接受新调用。可信本机插件是进程内代码，不宣称为恶意代码沙箱。

## 统一会话模型

会话、绑定和调用身份分别建模。会话保存模型上下文及真实后端会话 ID；绑定描述哪个 QQ 会话或插件使用它；权限根据本次调用身份判断，不从会话历史继承。

插件有稳定标识和具名会话（缺省 default），支持：

1. 独立会话：第一次调用自动创建并持久绑定，以后复用。
2. 按 QQ 会话分别维护：插件为每个群或私聊使用不同的会话名称或作用域。
3. 绑定已有会话：绑定明确的实际会话 ID，复用其上下文。

插件自建会话默认不注入 QQ 人设、聊天方案、回复协议或工具定义，只使用插件提供的任务与自己的历史；绑定已有 QQ 会话保留它原有上下文。本轮未提供隐式选择 QQ 人设的模式。

QQ 绑定切换不隐式迁移插件绑定。插件绑定的是具体会话，不是动态跟随某个 QQ 地址。解绑保留旧会话历史；下一次需要会话时自动创建。重启恢复原绑定；临时连接失败不当成会话删除。只有确认目标不存在时才允许建立替代会话，并记录上下文重新开始。

同一实际会话的调用统一串行，QQ 聊天、助手或插件不得交错写入。插件执行标明来源，结果返回插件，不因共享 QQ 会话自动发送消息；工具权限按该次调用重新确定，不继承历史主人的权限。

## 内部服务与主人管理入口

插件使用宿主模型服务选择已配置供应商和模型，密钥不返回插件目录或模型。持久模式复用绑定，单次生成也通过受管理的执行完成。插件业务记录（发布历史、素材和说说编号）放在持久存储，按需提供给模型，不把全部业务数据逐轮重复注入。

会话管理提供：按群号/私聊账号解析绑定、列出会话及引用、创建、更换绑定、新建并绑定、解绑和状态查询。聊天侧入口全部限主人，归入二级会话管理目录；插件内部通过宿主服务调用，命令的调用者权限由插件入口检查。

异步任务使用插件/任务的资源作用域，图片不必先发进 QQ 才能用于空间。调度、生成、文案和发布可组合，步骤记录与发布回执持久化；已确认发布不因重启重复提交，未知发布保留证据而不自动重发。

## 控制台

“会话与日志”中提供插件会话管理。列表显示插件、用途、模型、会话短编号、运行状态、最近使用；操作包含详情、更换绑定、新建并绑定、解绑。更换绑定弹窗可按群号、QQ 号、插件名称或会话 ID 查找目标，也可新建。

完整 ID、共享关系及技术状态在只读详情窗口显示。QQ 会话与插件会话共享时展示关联对象，解绑与删除历史明确区分。控制台不成为模型提问或逐次工具审批入口。

## 分阶段交付记录

- 可信插件上下文新增 `runtime.capabilities`、`runtime.models` 和 `runtime.sessions`；宿主提供真实插件身份和生命周期。
- QQ 协议能力采用明确版本能力表或协议端返回的动作清单；未核验的动作不展示为可用。模型使用目录按需展开，插件直接调用能力服务。
- 插件默认自动建立具名持久会话，也可显式绑定或单次创建；模型调用不自动发 QQ、不运行工具。业务副作用由插件调用能力服务编排。
- 会话管理增加插件绑定、新建、解绑、未知状态核对及 QQ 更换绑定。实际 DSH 历史保留；本轮不提供删除 DSH 会话。
- 相同实际会话有界串行，运行停止后拒绝新调用；未知执行保留绑定，核对原请求，不自动重复提交。
- 插件用量按插件来源和实际会话记录。公开接口和示例见 [插件模型](PLUGIN_MODELS.md) 与 [扩展开发](EXTENDING.md)。
- 调度沿用框架已有任务与日历钩子；本轮提供组合基础服务，不预装每天发布的业务插件。协议原生媒体参数可供可信插件直接使用，不要求先发到 QQ 登记。
