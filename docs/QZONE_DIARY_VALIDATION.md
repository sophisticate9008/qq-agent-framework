# 空间生活日记接入验证

本次交付先验证宿主能力，再装配可选业务插件。账号、参考图、模型凭据、生成图片和真实会话日志保存在本机私有运行目录，不进入仓库。

## 通用机制

- 持久插件会话：真实 DSH 中创建、复用、解除绑定、重新绑定与继续上下文均通过。修正了自定义记录未标记可忽略、运行目录缺失和消息来源判断的问题。
- 原生图片输入：插件模型服务接收有界图像附件，核对实际格式、大小和模型能力；视觉会话实际读取生成图片。图片不是以说明文字或 Base64 正文代替视觉输入。
- 持久定时器：一次性时间点和每日/每周规则统一运行，按插件隔离，回调随生命周期结束，重启不重复已开始且结果未知的工作。
- 扩展目录：插件注册摘要、schema 与执行器；通过共享目录按需发现和调用，撤销登记后不可调用，写调用保存幂等证据。
- 生图服务：业务插件依赖 `image-generation` v1，只取得图片字节与哈希，发布使用独立协议能力。

## 可重复验证

`test/plugin-tool-directory.test.ts`、`test/plugin-scheduler.test.ts`、`test/qzone-diary.test.ts` 和 `test/qzone-diary-package.test.ts` 本次合计 42 项通过，覆盖：

- 真实包依赖、服务版本、安装/停止以及启动失败时资源回收。
- 每日 1–3 个窗口、持续写作会话、过慢规划后的窗口内顺延。
- 首版通过、一次/两次重生成、三版均不通过即跳过。
- 图文不一致、图片存在问题、暂停后不发布。
- 同一已审查预览只发布一次；未知发布不重放。
- 七天结束记录保留、未知记录保留与时间边界。

这些测试的模型和协议结果可控，不代替真实外部验证。

## 真实模型与模拟 QQ

独立 DSH 的请求记录确认：插件写作会话不注入 QQ 聊天人设、聊天方案或工具；视觉请求携带实际图片附件。写作会话可恢复之前的上下文。

真实模拟 QQ 使用正式的 `qzone-diary` 公共包，关闭生成和发布。模型实际调用能力目录找到 `extension.qzone-diary.status`，调用后再回复。检查 `request/header.tools`：

- 顶层为 18 个工具。
- 177 个协议原子能力和三个日记插件工具均没有全部展开成顶层 schema。
- 查询状态没有创建日程、模型绑定、生图任务或空间写请求。
- 回复进入本地模拟捕获，没有发往真实 QQ。

另外通过通用目录夹具验证了主人写操作、普通成员拒绝与重复写去重。

## 图文流程

真实链路已完成：独立写作会话规划生活片段 → 同会话写文案和画面要求 → 生图服务加入私有角色参考 → 实际生成图片 → 独立视觉请求检查结构及文案匹配 → 保存已通过预览。人工检查与模型复核一致；模型复核不能保证发现全部图像问题。

空间协议返回不成功时不会标为已发布或自动循环重试。最终对外发布与本机部署的回执保存在私有运行记录中。
