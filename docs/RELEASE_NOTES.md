# 发布记录

## v1.2.0 · 统一插件服务、热重载与空闲性能优化

发布于 2026-10-29。框架、TypeScript SDK 与 DSH 桥接插件包版本为 `1.2.0`。

### 插件服务与热重载

- 内置能力与插件能力统一使用版本化服务契约、依赖声明、发布与取得入口；登记包含服务用途、来源、方法及运行状态。
- 协议、模型、持久会话、日程、媒体、工具、扩展管理、用量和观察事件通过绑定插件身份的宿主客户端提供。服务取得不隐式授权，也不把服务目录全部注入模型工具。
- 提供稳定服务代理及可替换行为 handler。兼容实现可热重载，已开始的调用在原代排空；加载失败保留当前实现，契约或注册结构变化需完整应用。
- 热重载共享未变化的源码文本，并增加默认 64 MiB 去重源码预算；保留最多 64 代与旧任务的延迟导入语义。
- 提供完整 TypeScript SDK 示例及服务规范、生命周期、取消、幂等与恢复说明。

### 持久日程与空间生活日记

- 通用插件日程支持持久规则、发生记录、取消与长任务期限，供插件组合使用。
- 可选空间生活日记插件每天在配置时间窗口内安排合计 1–3 次图文，使用自己的持久写作会话、生图和独立视觉检查，最多重新生成两次。
- 日程重启后沿用已保存计划，发布结果未知时不自动重复。工作流支持热重载，私人配置、素材及运行数据不随安装包分发。
- 修复插件持久模型会话和原生图像输入通路，并补全模拟入口与按需工具目录的调用链。

### CPU 与内存

- 空闲工具通道改为有界等待，有工具入队立即唤醒；正在执行时保留短轮询取消检查，旧插件维持原行为。
- 空队列通过存储变更令牌避免重复扫描，仍检测其他连接写入；SQLite 返回值保持完整校验和深冻结，减少重复深拷贝。
- 本机 DSH 凭据每次仍核验安全路径、权限与文件变化，未变化时复用 cookie；只读 YAML 使用完整内容键的有界缓存。
- 日历纯计算采用有界缓存；空闲规则不再每秒写入进度，跨过计划发生点时立即持久保存，保留重启、回拨和未知记录语义。
- 资源结果及测量边界见 [性能审查](PERFORMANCE_AUDIT_2026-10-29.md)。

### 安装与兼容

Release 提供 `qq-agent-framework-sdk-1.2.0.tgz`、`qq-agent-framework-dsh-bridge-plugin-1.2.0.tgz` 和 `SHA256SUMS`，源码由 GitHub 提供，不发布到 npm 注册表。Node.js 仍要求 `>=24.12.0`；DSH SDK / Cordis 仍为 `0.2.1-rc.2` / `4.0.5`。

框架继续兼容已识别的旧桥接插件；工具等待优化需要更新并加载新版 DSH 桥接插件。服务使用方需声明其提供包与服务依赖；参考 [服务规范](SERVICE_CONVENTIONS.md)、[热重载示例](../examples/reloadable-plugin/README.md) 与 [升级说明](OPERATIONS.md#升级与备份)。本版不清空会话、账本或插件日程，不改白名单与主人权限。

## v1.1.0 · 模型能力补全与统一会话管理

发布于 2026-10-28。框架、TypeScript SDK 和 DSH 桥接插件统一升级为 `1.1.0`。

### 模型可用的 QQ 能力

- 新增 `qaf_capability_catalog` 与 `qaf_capability_call`。模型先按分类或关键词查找能力，再读取具体参数并调用，低频管理接口不必全部塞入每轮工具定义。
- 补齐 QQ 协议能力目录，登记 NapCat 4.18.41 的 177 个生产动作；实际开放范围取决于当前协议端已确认支持的接口，不表示每个动作都已进行真实账号操作验证。
- 补全收藏表情添加、删除和备注修改，消息贴表情与移除、自身群名片修改、自主撤回自身消息。内置聊天方案增加按语境收藏和使用表情的指引。
- 日常互动沿用会话准入；账号和管理类敏感操作核验真实主人。可信插件通过宿主能力服务调用，按插件身份与调用方策略校验，不伪装成 QQ 主人消息。

### 插件模型与媒体服务

- 插件可通过 `runtime.models` 使用已配置供应商与模型，读取模型目录，选择思考强度，执行单次生成或使用具名持久会话。
- 提供插件会话创建及绑定服务。插件可建立自己的会话，也可明确绑定已有模型会话；生成结果返回插件，QQ 发送等操作通过宿主能力服务执行。
- 模型请求与插件生命周期、排队限制及持久执行记录关联；同一模型会话串行执行，结果未知时可核对原请求。
- 新增 `runtime.media.readImage`，插件可以读取当前会话中已登记图片的原始字节、类型和摘要，复用会话范围及有效期校验，减少重复建立媒体登记链路。

### 会话与账本变更

- 控制台增加 QQ 与插件会话管理，支持查询、新建、换绑、解绑及运行状态核对；未绑定的插件会话也有管理入口。
- 主人可通过按需会话目录工具查询实际模型会话 ID、创建和调整绑定。调整当前 QQ 会话时，可等待本轮处理及发送结束后执行。
- 绑定固定指向实际 DSH 会话。QQ 换绑后，绑定原会话的插件继续使用原会话；解绑保留模型历史，不删除 DSH 会话。
- 使用绑定版本校验和共享会话队列处理并发变更；独立助手的工作子会话不接受 QQ 或插件共享绑定。
- 账本增加插件来源标签与筛选，共享会话中的模型用量按实际请求及执行轮次归属，便于区分 QQ 聊天和插件调用。

### 控制台与维护

- 低频接口按用途聚合为能力包，在侧栏中搜索、浏览工具及参数说明。
- 助手设置读取与连接核验分离，工作记录归入会话与日志。
- 日常 CI 保留凭据扫描、类型检查和快速测试，完整验证改为手动工作流。

### 安装与升级

| 项目 | 版本与要求 |
| --- | --- |
| 框架源码 | `v1.1.0`，Node.js `>=24.12.0` |
| TypeScript SDK | `qq-agent-framework-sdk-1.1.0.tgz` |
| DSH 桥接插件 | `qq-agent-framework-dsh-bridge-plugin-1.1.0.tgz` |
| 外部 DSH SDK / Cordis | `0.2.1-rc.2` / `4.0.5`，保持精确 peer 版本 |
| QQ 协议端 | 已登录的 OneBot v11 服务，具体能力按协议端版本开放 |

请配套更新框架与 DSH 桥接插件；旧框架不识别新插件包版本。框架仍识别此前发布的桥接描述，线协议及持久 schema 保持原标识。升级与加载步骤见 [运维说明](OPERATIONS.md#升级与备份) 和 [DSH 接入](DSH.md)。

Release 附带两个 npm 安装包及 `SHA256SUMS`，源码压缩包由 GitHub 提供；不向 npm 注册表发布。私有运行目录中的业务插件不包含在安装包内。扩展服务的接入方式见 [扩展开发](EXTENDING.md)。

## v1.0 首次正式发布

标签：`v1.0`。框架、TypeScript SDK 和 DSH 桥接插件包版本均为 `1.0.0`。

QQ Agent Framework 面向 QQ 群聊与私聊，提供中文控制台、连续聊天、按需媒体读取、后台助手及持久执行记录。AI许愿生成的，目前自用

### 本版内容

- QQ 账号与会话隔离、昵称及引用唤醒、群聊未读合并和选择性参与。
- 真实来源与白名单权限校验、显式发送工具、持久 outbox 和未知结果核对。
- 图片、GIF、文件及转发读取；可选视频抽帧；中文 Markdown、代码和公式转图。
- QQ 表情、收藏表情、戳一戳、撤回和协议支持的空间说说发布及删除。
- 可配置的独立后台助手，支持任务追加、停止、结果及真实附件回传。
- TypeScript SDK、功能包、宿主服务、扩展热重载登记，以及记忆、偏好和提醒底层服务。
- 中文安装、使用、升级、运维、扩展与安全说明。

### 安装包与兼容

| 项目 | 版本与要求 |
| --- | --- |
| 框架源码 | `v1.0`，从源码安装及构建，Node.js `>=24.12.0` |
| SDK | `qq-agent-framework-sdk-1.0.0.tgz`，供独立 TypeScript 扩展安装 |
| DSH 桥接插件 | `qq-agent-framework-dsh-bridge-plugin-1.0.0.tgz` |
| 外部 DSH SDK / Cordis | `0.2.1-rc.2` / `4.0.5`，仍按精确 peer 版本接入 |
| QQ 协议端 | 独立运行且已登录的 OneBot v11 服务，扩展动作依实际版本 |

Release 提供两个本地 npm 安装包和 `SHA256SUMS`，源码压缩包由 GitHub 提供。框架仓库仍保留 `private: true` 防止误发 npm，这不影响 GitHub 仓库公开；本版没有向 npm 注册表发布包。

桥接插件包版本升到 `1.0.0`，线协议标识及持久 schema 不因发版改号；框架继续识别历史 `0.1.0`、`0.2.0` 桥接描述。新插件需要配套更新框架后加载，旧框架只认识历史版本，不能直接保证接入新包。

开始使用见 [安装教程](INSTALL.md) 与 [使用教程](USAGE.md)，插件加载见 [DSH 接入](DSH.md)，已有部署见 [升级与备份](OPERATIONS.md#升级与备份)。

### 首发整理与 CI 修复

修复契约层越层依赖、字体大小检查以及 DSH 插件测试的 SDK 类型不匹配；补齐源码规则夹具的配置文件。字体以明确大小和 SHA-256 核验，不放宽其他文件大小及权限边界。CI 追加依赖安全审计，以及固定版本 Gitleaks 完整历史扫描并强制脱敏输出，保留原框架、SDK、浏览器和插件隔离验证。移除仅用于样式导入的 shadcn CLI 依赖链，原样保留其 CSS 与许可；插件开发环境将 Zod 覆盖到修复版 `4.6.7`。

首发前进行当前待发布内容与可达历史的凭据、隐私模式及资源核查，实际结果见 [验收记录](VALIDATION.md)。自动扫描不构成所有隐私均不存在的证明。

### 使用范围

- Linux 提供本机 DSH 自动发现；Windows/macOS 使用高级接入，未提供同等运行验收保证。
- DSH 与 QQ 协议端独立安装；模型和协议能力以实际元数据和接口为准。DSH 宿主的旧 Zod 依赖需由部署者显式更新，插件的安全覆盖不会传递到宿主，见 [安全依赖覆盖](DSH.md#安全依赖覆盖)。
- 记忆、偏好和提醒默认提供底层服务，模型工具和上下文由扩展接入。
- 视频观察默认关闭，只观察抽样画面，不转写音轨；语音转写需要外接服务。
- 独立助手可在真实主人准入后获得全本机文件及命令权限，审批为 `never`；可信扩展在宿主内执行，不提供恶意代码沙箱。
- 普通配置应用会保留已有模型历史，需要重新加载现有提示词时可能重启受管 DSH。
- 模型会话历史由 DSH 管理，框架控制台仅提供独立绑定及账本操作。
