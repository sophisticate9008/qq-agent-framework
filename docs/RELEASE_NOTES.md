# v1.0 首次正式发布

标签：`v1.0`。框架、TypeScript SDK 和 DSH 桥接插件包版本均为 `1.0.0`。

QQ Agent Framework 面向 QQ 群聊与私聊，提供中文控制台、连续聊天、按需媒体读取、后台助手及持久执行记录。AI许愿生成的，目前自用

## 本版内容

- QQ 账号与会话隔离、昵称及引用唤醒、群聊未读合并和选择性参与。
- 真实来源与白名单权限校验、显式发送工具、持久 outbox 和未知结果核对。
- 图片、GIF、文件及转发读取；可选视频抽帧；中文 Markdown、代码和公式转图。
- QQ 表情、收藏表情、戳一戳、撤回和协议支持的空间说说发布及删除。
- 可配置的独立后台助手，支持任务追加、停止、结果及真实附件回传。
- TypeScript SDK、功能包、宿主服务、扩展热重载登记，以及记忆、偏好和提醒底层服务。
- 中文安装、使用、升级、运维、扩展与安全说明。

## 安装包与兼容

| 项目 | 版本与要求 |
| --- | --- |
| 框架源码 | `v1.0`，从源码安装及构建，Node.js `>=24.12.0` |
| SDK | `qq-agent-framework-sdk-1.0.0.tgz`，供独立 TypeScript 扩展安装 |
| DSH 桥接插件 | `qq-agent-framework-dsh-bridge-plugin-1.0.0.tgz` |
| 外部 DSH SDK / Cordis | `0.2.1-rc.2` / `4.0.5`，仍按精确 peer 版本接入 |
| QQ 协议端 | 独立运行且已登录的 OneBot v11 服务，扩展动作依实际版本 |

Release 提供两个本地 npm 安装包和 `SHA256SUMS`，源码压缩包由 GitHub 提供。框架仓库仍保留 `private: true` 防止误发 npm，这不影响 GitHub 仓库公开；本版没有向 npm 注册表发布包。

桥接插件包版本升到 `1.0.0`，线协议标识及持久 schema 不因发版改号；框架继续识别历史 `0.1.0`、`0.2.0` 桥接描述。新插件需要配套更新框架后加载，旧框架只认识历史版本，不能直接保证接入新包。

开始使用见 [安装教程](INSTALL.md) 与 [使用教程](USAGE.md)，插件加载见 [DSH 接入](DSH.md)，已有部署见 [升级与备份](OPERATIONS.md#升级与备份)。

## 首发整理与 CI 修复

修复契约层越层依赖、字体大小检查以及 DSH 插件测试的 SDK 类型不匹配；补齐源码规则夹具的配置文件。字体以明确大小和 SHA-256 核验，不放宽其他文件大小及权限边界。CI 追加依赖安全审计，以及固定版本 Gitleaks 完整历史扫描并强制脱敏输出，保留原框架、SDK、浏览器和插件隔离验证。移除仅用于样式导入的 shadcn CLI 依赖链，原样保留其 CSS 与许可；插件开发环境将 Zod 覆盖到修复版 `4.6.7`。

首发前进行当前待发布内容与可达历史的凭据、隐私模式及资源核查，实际结果见 [验收记录](VALIDATION.md)。自动扫描不构成所有隐私均不存在的证明。

## 使用范围

- Linux 提供本机 DSH 自动发现；Windows/macOS 使用高级接入，未提供同等运行验收保证。
- DSH 与 QQ 协议端独立安装；模型和协议能力以实际元数据和接口为准。DSH 宿主的旧 Zod 依赖需由部署者显式更新，插件的安全覆盖不会传递到宿主，见 [安全依赖覆盖](DSH.md#安全依赖覆盖)。
- 记忆、偏好和提醒默认提供底层服务，模型工具和上下文由扩展接入。
- 视频观察默认关闭，只观察抽样画面，不转写音轨；语音转写需要外接服务。
- 独立助手可在真实主人准入后获得全本机文件及命令权限，审批为 `never`；可信扩展在宿主内执行，不提供恶意代码沙箱。
- 普通配置应用会保留已有模型历史，需要重新加载现有提示词时可能重启受管 DSH。
- 模型会话历史由 DSH 管理，框架控制台仅提供独立绑定及账本操作。
