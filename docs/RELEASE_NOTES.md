## v1.5.2 · 修复冷会话恢复竞态与日程补执行

- 日程增加“立即执行”。插件显式核验业务是否可安全执行，宿主以 CAS 保存独立手动发生和执行占用，后台运行不随网页关闭取消，历史标记手动来源。单次安排受理后不再到点重复触发，周期保留后续安排；中断或结果未知不重放。

- 修复纯 @ 机器人没有附带空格时被当作空内容丢弃、附带空格时又被模型当成空消息点评的问题。

- 移除会话列表中始终显示“未提供”的最近记录占位列。
- 同步任务详情订阅的生命周期测试预期。

## v1.2.0 · 统一插件服务、热重载与空闲性能优化

发布于 2026-10-29。框架、TypeScript SDK 与 DSH 桥接插件包版本为 `1.2.0`。

### 插件服务与热重载

- 内置能力与插件能力统一使用版本化服务契约、依赖声明、发布与取得入口；登记包含服务用途、来源、方法及运行状态。
- 协议、模型、持久会话、日程、媒体、工具、扩展管理、用量和观察事件通过绑定插件身份的宿主客户端提供。服务取得不隐式授权，也不把服务目录全部注入模型工具。
- 提供稳定服务代理及可替换行为 handler。兼容实现可热重载，已开始的调用在原代排空；加载失败保留当前实现，契约或注册结构变化需完整应用。
- 热重载共享未变化的源码文本，并增加默认 64 MiB 去重源码预算；保留最多 64 代与旧任务的延迟导入语义。
- 提供完整 TypeScript SDK 示例及服务规范、生命周期、取消、幂等与恢复说明。

### 持久日程与插件接入

- 通用插件日程支持持久规则、发生记录、取消与长任务期限，供插件组合使用。
- 修复插件持久模型会话和原生图像输入通路，并补全模拟入口与按需工具目录的调用链。

### CPU 与内存

- 空闲工具通道改为有界等待，有工具入队立即唤醒；正在执行时保留短轮询取消检查，旧插件维持原行为。
- 空队列与空任务索引通过存储变更令牌避免重复扫描，仍检测其他连接写入；SQLite 返回值保持完整校验和深冻结，减少重复深拷贝。
- 本机 DSH 凭据每次仍核验安全路径、权限与文件变化，未变化时复用 cookie，系统时钟回拨后重新签发；只读 YAML 使用完整内容键的有界缓存。
- 日历纯计算采用有界缓存；空闲规则不再每秒写入进度，跨过计划发生点时立即持久保存，保留重启、回拨和未知记录语义。
- 两段空闲工具观察采样中，框架平均 CPU 为 8.21% / 9.49% 单核，优化前为 58.28% / 66.94%；DSH 为约 5.8%，优化前约 16.8–23.2%。这是短时低负载观测，内存变化也受重启影响。详细测量边界见 [性能审查](PERFORMANCE_AUDIT_2026-10-29.md)。

### 安装与兼容

Release 提供 `qq-agent-framework-sdk-1.2.0.tgz`、`qq-agent-framework-dsh-bridge-plugin-1.2.0.tgz` 和 `SHA256SUMS`，源码由 GitHub 提供，不发布到 npm 注册表。Node.js 仍要求 `>=24.12.0`；DSH SDK / Cordis 仍为 `0.2.1-rc.2` / `4.0.5`。

框架继续兼容已识别的旧桥接插件；工具等待优化需要更新并加载新版 DSH 桥接插件。服务使用方需声明其提供包与服务依赖；参考 [服务规范](SERVICE_CONVENTIONS.md)、[热重载示例](../examples/reloadable-plugin/README.md) 与 [升级说明](OPERATIONS.md#升级与备份)。本版不清空会话、账本或插件日程，不改白名单与主人权限。

### 插件模型与媒体服务

- 插件可通过 `runtime.models` 使用已配置供应商与模型，读取模型目录，选择思考强度，执行单次生成或使用具名持久会话。
