# 安全边界

本轮只交付本地演示。不要将其直接暴露到公网，不要用它连接生产凭据。

## 权限与副作用

- 功能代码与宿主适配器均为可信代码；能力 SDK 约束正确接入的代码，不是 JavaScript 沙箱。
- 安装、声明、偏好和人设不会创建授权。授权限定功能、会话、能力、有效期和有限尝试预算。
- 发送在真正调用适配器前重新检查；排队期间撤销可阻止后续动作，已经开始的外部动作不能承诺回滚。
- 不在最终授权和适配器调用之间执行 observer 回调；观测失败不能改变业务执行结果。
- 明确拒绝、未知和确认分开；传输异常按未知处理，无自动重试。confirmed 的意义由适配器契约决定。
- 事件去重仅限内存窗口，通用能力无持久幂等，进程重启后不可假定消息或任务未执行。

## 管理界面

- CLI 强制回环绑定；直接使用底层 createAdminServer 的宿主也必须自己保证监听边界。
- 快照 API 与演示写 API 需要至少 24 字符的 Bearer 口令；等长值使用 timing-safe 比较。
- 写请求要求 JSON、严格同源与体积上限；不提供 CORS 放行或任意路径静态文件。
- 页面使用 textContent 展示动态数据，限制脚本来源；口令不写 URL、日志或浏览器持久存储。
- 静态资产缓存有界且只缓存白名单文件；不缓存授权检查或动态管理快照。
- HTTP 请求/头/连接设定时间和大小限制；仍无分布式限流、用户体系、TLS 终止或完整抗 DoS 能力。
- 健康检查和静态资源公开，但不能直接读取受保护的快照；真实宿主不应把密钥交给 snapshot 回调。

## 公开发布检查

`npm run check` 检查类型、源文件语法、符号链接及若干已知凭据格式；它不是完整秘密探测器。
发布前仍需检查 Git 文件清单、远端、实际账号和差异，不上传旧人设、私有配置、聊天、参考图或运行目录。
`.gitignore` 排除运行数据、构建输出、常见环境/密钥文件；不能因此认为任意路径都可安全暂存。

依赖仅为开发用 TypeScript、Node 类型和 Playwright；锁定依赖版本。构建后应用本身不需第三方运行库。
生产适配器、持久任务、远程管理和不可信插件都需要新的安全设计与独立验收。
