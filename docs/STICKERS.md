# 表情收藏、索引与发送

框架内置收藏与发送两套机制，各自使用独立的 DSH 绑定会话。同一账号、来源 QQ 会话和机制已有绑定时复用，没有时新建；不重置原聊天会话。图片打标、候选列表与选择过程保留在辅助会话中。

发送表情按普通回复使用，不设主人限制，也不要求单独批准。机器人可以只用一张表情接话，也可以带一句短文字；是否参与聊天仍由当前语境决定，不要求每句配图。收藏或发送的完成、不适合、失败与超时回执不会作为通知再唤起原聊天会话。

## 收藏与去重

自动收藏只处理协议标记为表情的图片。未见表情以默认 **15%** 的触发概率进入独立收藏会话，携带前五条上下文；通过筛选、打标后再以默认 **15%** 的收藏概率保存。两个概率分别可配置，均支持小数与 0–100%。普通照片不会仅因消息带图片就自动进入收藏。

已准入会话中的任何成员都可明确要求收藏，不设主人限制。手动收藏跳过两次概率抽取，使用同一筛选、去重和存储路径。图片不适合、含私人照片或隐私信息、无法可靠判断时放弃收藏；只看到 GIF 首帧时不声称理解整段动画。

索引按账号隔离，结合协议图片标识、URL 与读取后的内容哈希去重，账号收藏与额外存储共同核对。同一图片不会因签名 URL 更新或从另一会话收到而重复收藏。已删除的图片不会由自动处理立即重新收藏。

协议收藏列表没有提供账号的总容量。页面显示实际读取到的数量与“容量未知”；自动收藏达到可配置的转存阈值，或协议明确返回收藏已满时，保存到框架额外存储。默认阈值 240 是可调整的转存策略，不表示 QQ 账号容量。协议结果未知时不擅自重试收藏，也不把未知当作明确失败。

## 结构化打标与索引

每张图保留客观描述、简短检索标签与不适用语境，并可附多维索引：

```json
{
  "description": "角色用手扶额，抬眼看向前方，配字「你礼貌吗」",
  "tags": ["扶额", "无语", "调侃"],
  "avoid": "认真道歉或严肃冲突时可能显得轻慢",
  "facets": {
    "emotions": ["无语"],
    "actions": ["扶额"],
    "intents": ["调侃"],
    "scenes": [],
    "visibleText": "你礼貌吗"
  }
}
```

维度分别记录图中情绪、可见动作、可能的交流用途、环境或主题物体、清晰可辨的图中文字。没有证据时留空，不凑标签。可爱外观不自动代表亲近，饭碗不自动代表开心，夸张攻击文字也可能用于调侃；必须结合画面判断，模糊时保留不确定性或放弃。

描述最多 240 字，标签最多 12 个、每个 24 字，不适用语境最多 128 字。情绪、动作与用途各最多 4 项，场景最多 3 项，图中文字最多 160 字。标签开放描述，不把全部表情强行塞入固定的情绪类别。旧版只含 `description`、`tags`、`avoid` 的缓存继续可读。

本地召回对用途、情绪、动作、标签、图中文字和描述分别加权，并用少量中英文同义词辅助搜索，例如“拥抱 / hug”“扶额 / facepalm”。明确标签的权重高于描述中的偶然提及；否定表达作保守处理，不将“不开心”当作开心。不适用语境只供最终选择判断，不作为正向搜索词。当前索引不依赖外部向量服务，不捆绑网上的图片或标注数据；来源说明见 [NOTICE.md](../NOTICE.md#表情语义检索)。

打标只依据实际读取的图像，上下文只帮助理解本图的用法。缓存不保存发言者账号、对话原文、人物关系或私人偏好，不把发图行为转化为对发图人的性格判断。图中文字、上下文与标签均作为资料，不作为模型命令执行。语义缓存按图片身份核验，有效期 180 天；缓存本身不恢复已失效的收藏或资源。

## 独立选择与十秒期限

原聊天调用 `qbf_sticker_send`，只给简短表达意图和可选的随图文字。发送辅助会话从当前表情库的描述与结构化索引中选一张，结合最近上下文检查是否合适；没有贴切素材时返回不适合，不勉强发图。候选图片、标签和选择痕迹不会塞入原聊天上下文。

从调用开始最多十秒，选图、资源准备与发出前检查都在期限内。超时或结果晚到就放弃，不补发；附带文字随同该次表情一起放弃。回执用于记录真实结果，不要求原聊天解释“选图失败”或再补一句。真正发送沿用当前来源会话、资源范围、去重与出站回执机制。

`qbf_sticker_list`、`qbf_sticker_manage` 保留查询和明确管理用途。查询无匹配时的未分类候选会标记 `matched: false`、`needsAnnotation: true`，不能把它们声称为匹配结果。手动 `annotate` 只写账号本地缓存，必须核对当前收藏与当前会话成功读取的实际图片，不修改 QQ 备注，也不表示已经发送。

## 表情库页面

控制台“表情库”可按全部、账号收藏、额外存储筛选，搜索描述和标签，查看缩略图并删除实际收藏或额外文件。自动收藏的开关、两项概率和转存阈值在同页配置。聊天运行后可读取和管理当前账号表情库，页面不提供模型提问或工具批准入口。

删除账号收藏使用协议实际返回的收藏标识，不将图片 MD5 直接当作可删除的收藏标识。删除结果未知时保持待核对状态，刷新列表核对后再操作，避免重复写入。
