# 工作台使用说明

工作台用于配置、查看运行状态和维护记录。日常聊天、模型提问和独立工作请求在所属 QQ 会话进行。工具随会话白名单开放；敏感操作仅限实际配置主人，无需逐次批准。

最近活动保留允许会话的“收到消息”。普通群聊旁听仍保留为上下文，不额外生成处理日志。进入回复流程的消息（私聊、@、昵称、引用或有效续聊）按实际排队、提交、发送或异常记录进展；只有模型确认接收请求后才显示等待回复，这不代表回复已完成。工具挂载失败会显示所属会话、失败阶段与错误码。

配置以紧密卡片组合呈现，短字段同行，长文本保留编辑空间。只读详情在侧窗显示：固定浅色标题栏，正文使用紧凑的中文摘要、分组字段与状态表格；配置指纹和原始对象通过独立技术记录弹窗查看，不直接铺满侧窗。删除在确认窗口处理。手机侧栏可点击遮罩、选择页面或按 Esc 关闭。首页的三项回复设置独立保存；方案应用复用完整编辑页的版本核对与保存流程。

## 登录与页面导航

打开启动时显示的管理地址。在“连接你的工作台”中，按页面提示的本机文件位置复制管理员令牌，进入工作台。令牌只用于建立本浏览器的访问会话；页面使用 HttpOnly cookie 保持登录，默认绝对有效期为 7 天。点击右上角“断开连接”会撤销当前访问会话。

侧栏按任务组织：

| 入口 | 主要内容 |
| --- | --- |
| 连接与概览 | QQ、DSH、后台助手摘要，当前聊天方案、回复方式、访问范围与最近活动 |
| 连接设置 | QQ、DSH 与聊天运行三张摘要卡，连接参数和运行操作使用窗口 |
| 人设编辑 | 左侧人设目录，右侧身份与表达双栏，唤醒和删除使用窗口 |
| 聊天方案 | 方案目录、模型与人设关联、指令、应用，以及助手设置与工作记录 |
| 模型服务 | 服务目录、连接参数与模型表，模型编辑及引用管理使用窗口 |
| 会话与日志 | 会话表格、逐会话诊断与媒体详情，执行日志、QQ互动和独立工作页签 |
| 用量统计 | Token、费用、时间走势、按模型的调用采样，以及会话、逐轮、调用记录 |
| 功能与扩展 | 框架内置入口与 Agent 扩展页签，回复方式集中到首页 |
| 访问与设置 | 主人与白名单、回复与超时、管理端监听设置 |


顶部“搜索工作台”可搜索页面、分组和字段名称。“本页目录”用于跳转当前页的分组。搜索会定位目标所在的分组或标签；禁用、尚未配置或缺少前置条件的字段仍可被找到，页面会说明不能聚焦的原因。搜索和导航不会保存配置。

卡片和列表按内容高度显示；长列表达到上限后在区域内滚动。保存状态和按钮同排，窄屏自动换行。人设和聊天方案使用顶部选择条与全宽编辑区，长文输入框可拖高，编辑内容随页面滚动；本页目录通过按钮浮窗打开。

右上角可选择跟随系统、日间或夜间模式。窄屏通过“切换侧栏”打开导航；长表格在各自区域滚动，页内目录也可单独展开。

框架工具按白名单提供，工具状态在“功能”的框架内置与 Agent 扩展页签查看。已有工具组合配置继续保留。

连接页不再提供独立的会话兼容性检查、原配置回填或基线原文查看；方案和人设变更通过对应卡片的“应用”衔接已有会话。

连接页分别显示 WebSocket 当前状态和最近诊断。入站事件处理失败或超时会保留为“最近入站处理异常”，连接仍正常时继续显示“WebSocket 已连接”；只有当前鉴权失败才提示核对 WebSocket 专用密钥。接收与丢弃计数包含协议事件，不能直接当作聊天消息数量。聊天停止时仍可明确重新连接或断开。

## 第一次开始聊天

登录后，可从概览的“开始聊天”依次打开配置。每一步分别保存，最后明确应用。

1. **连接 QQ 与 DSH。** 在“连接”填写实际 QQ 接入所需的收发连接。普通本机 DSH 使用自动发现和本机鉴权；远程接入、手动地址和路径在高级设置中。保存收消息连接与聊天就绪是分别显示的状态。
2. **登记模型。** 在“模型”创建提供方，选择接口协议、填写所需凭据并登记模型。提供方名称和模型显示名称用于识别，API 模型 ID 用于实际请求。
3. **设置人设和聊天方案。** 在“伙伴 → 人设”填写并保存身份与表达风格。在“伙伴 → 聊天方案”选择模型和关联人设，填写方案指令；“保存聊天方案”用于只保存草稿，“更新聊天”会保存当前方案、选择启用并应用。
4. **设置主人与白名单。** 在“安全”明确主人账号及允许参与的群聊、私聊。功能参与范围、输出选项和人设内容各自保存，权限仍由访问控制核验。
5. **核对并应用。** 方案页点击“更新聊天”，其他应用入口按页面提示操作。普通流程会自动识别本机配置层与所选模型的元数据，按实际需要停止聊天、准备并应用配置、核对会话衔接，再启动聊天。

概览的步骤只表示已核对相应配置。启动前请查看缺失条件，启动后在真实 QQ 会话中核对消息结果；“已保存”本身不表示模型已经运行。

## 草稿、保存和应用

| 状态 | 含义与操作 |
| --- | --- |
| 未保存 | 编辑仍是草稿；当前方案可用“应用”一并保存和应用，其他配置分别保存或撤销 |
| 已保存待应用 | 配置已经保存；当前运行会话可能仍使用原配置 |
| 后台处理中 | 已确认的应用操作由服务端继续处理；页面只观察阶段 |
| 已生效 | 当前会话已报告匹配的运行配置；具体消息结果仍看实际记录 |
| 结果待核对／未知 | 保留原操作标识与证据，先读取或核对，不重复提交 |

普通配置草稿在当前工作台内存中保留：切页、折叠和返回编辑不会隐式保存。模型提供方的密码和密钥输入不随普通草稿保留，离开编辑页后需要重新填写。完整刷新或关闭浏览器后，未保存草稿不保证恢复；主动退出会清除草稿。

读取失败时，页面会标记不可用或待核对，并保留可用的上次结果、草稿。发生版本冲突或写入结果未知时，按页面入口读取已保存内容；需要继续编辑的表单，会要求明确核对后再允许新的保存。读取成功不代表上次外部应用已经成功。

聊天方案编辑卡片底部的“应用”使用同一流程：保存当前编辑的方案并将其选择为启用方案，然后只创建一个应用操作。已经保存且已启用的方案不重复保存。它不会代为保存其他人设、提供方、助手或手动 DSH 设置的草稿；未保存的手动 DSH 设置需要先处理。方案保存冲突或结果未知时，应用不会继续提交。

DSH 的普通应用使用持久操作标识。处理较慢时显示当前阶段，只查询同一个操作，不重复提交。关闭页面不会取消服务端已经确认的应用，回到同一账号可继续读取原操作。服务明确拒绝受理的请求显示拒绝原因，不当作已经发生的未知应用。

“核对并继续”作用于原操作。若写入已发生但尚未确认加载，后台先核验原配置版本、实际 DSH 预设与来源；证据齐全后沿原操作继续会话衔接和启动，跳过已经执行的停止、准备与应用。其他阶段仍按各自证据核对；不足时保留阻碍，不自动重放。

应用处理中可以“查看进度”；已知原操作结果未知时可以“核对并继续”。观察请求失败或尚未返回，不会将这些恢复入口一并锁住。读取旧阶段回包不会回退已经核对的新状态，也不会提交第二份应用。旧手动请求结果未知时，使用可见的“恢复操作”：它取得实际加载或安全停止与排空证据，恢复管理入口，保留当前草稿，不重复应用或启停。

人设编辑卡片底部只提供简短的应用操作与状态；先保存人设，再点击“应用”。当前方案未选用的人设不能从这里应用。操作编号、阶段和原因放在只读详情浮窗。连接页不再重复显示应用与重启卡片；手动部署设置从聊天方案的“高级设置”打开。

普通更新不要求重启 DSH。应用入口仅在等待加载或维护未结束时显示重启操作。实际设置仍待加载且本机管理器支持时，可明确选择“重启 DSH”，由服务暂停并排空聊天、重启指定实例、核验并恢复原运行意图；没有待续行应用时，原来停止的聊天保持停止；已有等待加载的应用则按原更新意图继续，最终聊天状态单独显示。重启结果未知时使用“恢复原重启”，只核对原操作，不重复重启。未配置受控管理器、目标不匹配或其他账号仍在使用同一实例时会说明不可用原因。

手动 DSH 详情中的恢复入口另有证据要求。只有后台核验实际应用记录后，页面才允许明确开始新的管理操作；任意一次成功刷新都不能代替应用核验。

## 人设、模型与独立助手

人设保存身份和表达风格，聊天方案保存模型选择、指令和群聊／私聊上下文策略。新建人设和方案会自动生成稳定标识；高级设置允许创建前调整标识，创建后固定。

模型选择可在方案内就地新建提供方或模型，保存模型目录后返回原选择位置。方案的其他草稿会保留，随后通过“保存聊天方案”或“更新聊天”明确提交。思考强度只允许选择实际模型声明的支持值；旧值尚未核验时仍显示在下拉框中并标记待确认。读取失败会说明已知原因，可点击“重新读取支持情况”恢复查询，不会自动改档。

模型提供真实容量信息时，新建方案尚未手改的默认容量可采用建议值。已有方案可点击“使用模型建议容量”，先查看模型窗口、最大输出与预留空间，再明确采用。自定义容量不会被自动覆盖；容量变化仍需通过应用及会话衔接核验。

删除人设、方案、提供方或模型时，先查看引用使用者。按页面操作更换目标或解除引用，再明确确认删除。仅聊天模式会保留助手目标，因此保留的助手目标也可能阻止删除模型。

“聊天模式”区分“仅聊天”和“聊天＋助手”。选择助手模型后点击“保存并启用”，自动保存、配置并核验助手目标；本机 DSH 需要重新加载时自动维护并恢复此前的聊天状态。助手模型可在运行中更新，独立目标卡片和确认复选框已移除。失败原因用简短中文显示，配置版本与状态码放入只读详情浮窗。旧版已保存但未启用的助手可直接点击同一卡片底部的“启用助手”。

“独立工作记录”可筛选、查看结果、迟到结果和回父会话的消息／文件回执。实际发起、追加、停止和恢复工作在所属 QQ 会话进行。工作中的模型问题回到 QQ；工具不再逐次等待确认。

## 功能、工具和内容

### 唤醒、回复与权限

“人设”中的“唤醒与续聊”保存呼叫昵称、引用唤醒和同人续聊时长，随所选人设生效，保存后即时更新。白名单内的私聊和群聊 @ 必定唤醒；没有额外参与开关或会话限制。

“回复方式”控制分气泡、媒体输出和长文转发等行为。白名单内会话可直接使用合并转发，无需额外授权或次数配置。

“功能”页分为两个页签：**框架内置**提供回复方式设置；**Agent 扩展**展示接入工具和扩展设置。运行与装配细节通过详情窗口查看。

工具使用当前会话白名单，媒体、记忆和工作结果保留所属会话边界。工作发起、追加、停止、恢复等敏感操作只接受实际主人请求。DSH 外部工具确认按当前请求来源自动处理，主人请求放行，其他发言者的请求拒绝。模型需要补充信息时仍会在 QQ 提问。

功能包设置按当前服务提供的字段编辑，显示实时应用或重启条件。本地扩展在宿主进程中运行。旧授权文档和历史记录保留，页面不再提供工具额度、逐次审批或单独转发授权入口。

### 插件服务

记忆、偏好和定时任务由插件通过宿主服务接入。功能页不提供手工提醒规则或记忆编辑表单，框架不默认注册提醒和记忆模型工具，也不在每条聊天输入中自动查询记忆。定时任务注册、执行记录、记忆来源与范围校验等底层能力保留。

人设页管理身份、表达和唤醒方式。外部角色资料来源和多图参考由插件扩展提供。

## 会话状态与恢复

在“会话”选择目标 QQ 会话，查看绑定、排队数量、处理状态、期限和已读取的分页范围。排队消息到期会结束，不会永久锁住会话；旧执行结果未确认时自动核对，已提交输入不重复发送。筛选只作用于当前已加载记录；页面提示仍有后续时，可继续加载。

每行的“检查未回复”直接检查该会话，在浮窗显示原因和下一步，无需填写内部会话键。标识、原因码、扫描范围和模型容量收进只读技术详情；缺少证据时明确显示尚未确认。

媒体与引用区域区分登记记录、曾读取内容或字节、当前读取链和最近一次读取结果。历史曾读标记不覆盖当前失败；图片理解还取决于实际模型能力，语音需要实际转写服务。引用只有在同会话读取成功后才显示已核对；没有观测记录时保留未确认。

会话互动记录只读显示 QQ 所属会话、模型问题和外部工具自动处理结果。模型问题请回到 QQ 回答，页面没有答复或批准按钮。

### 执行结果核对

在“任务执行日志”打开目标记录，查看“执行结果与上下文恢复”：

1. 先“读取原执行与恢复结果”，检查当前状态和具体阻碍。
2. 明确确认后可“核对执行结果”。此操作只观察 SDK 持久证据，不重放旧请求或迟到输出。
3. 需要保留上下文恢复且条件允许时，先“预览保留上下文恢复”，核对原会话与计划，再“确认创建新的会话地址”。
4. 创建结果未知时，读取或“核对原恢复请求”，始终沿原恢复计划版本检查，不再创建另一份会话。
5. 按页面提示在“连接”明确重启聊天，建立核验后的会话关联。

证据不足会继续阻断。管理核对、恢复计划和 QQ 工具确认是不同操作，不能相互代替。

“解除绑定”支持运行中的空闲会话，保留旧模型历史、用量和执行记录，下次聊天建立新上下文。有未结束或结果未知的任务时会说明阻碍。

本机接入提供“删除”：输入“删除会话”确认后，暂停聊天与本机 DSH，在确认监听退出并取得所选会话文件锁后删除该模型会话、解除绑定并清除框架短期上下文，然后恢复服务。其他会话绑定与历史、QQ 消息和用量保留。页面查询同一次维护操作，未知结果不自动再次删除。远程或未配置本机管理器的接入不显示可用删除能力。

## 账号范围

连接页集中管理当前 QQ 与 DSH 接入。底层账号隔离、既有配置与会话记录保留；已迁入明确账号的部署继续使用原账号范围。

## 用量、导出与账本维护

用量页可查看总量、趋势、会话和逐轮记录。“详细数值”切换数值显示，不改变数据。统计详情通过只读窗口查看；会话、逐轮、调用记录通过页签切换，表格在卡片内滚动。选择会话后自动切换到该会话逐轮记录。图表悬浮查看桶详情，也可从“时间桶明细”选择并固定，移动端提示框保持在可见视口内。

费用是按有效价目表估算或已报告的金额，不能替代服务商实际账单。未知值保留未知；“已记录费用”可能只是已知金额小计。不同币种分开显示，覆盖不完整时不能将小计当作完整总账。

内置参考价目表可查看；人工单价覆盖在独立编辑窗口修改，仅影响后续入账估算，历史记录保留原价格与金额。

用量页顶部仅提供“清空账本”操作，不再单列归档与清理卡片。点击后确认清空已结算的当前账本与旧归档记录，无需选择时间、会话或逐批确认。清空保留单价设置、会话历史、未知轮次与执行证据，以及防止迟到重复入账所需的最小去重记录。新入账记录仍可继续出现。

清空前核对账本版本；冲突或结果未知时不自动重试，关闭对话框后刷新统计核对。

## 管理服务与独立网关

“安全”中的“回复与超时”控制聊天处理期限、超时提醒和停止策略。工具与停止操作按当前白名单和主人身份判断，不提供旧次数限制模式入口。

“管理端监听”更改工作台地址与端口，保存后点击“应用并重启”，再按新地址重新连接。HTTPS 反向代理、登录会话及部署路径保留在“管理端高级设置”。

独立出站接口供外部程序直接提交发送请求，不参与原生聊天的模型处理链路。控制台不再提供该接口的额度、期限、发送身份或协议配置；保留程序接口及已有配置供显式接入使用。

## 紧凑列表与自动维护

会话、附件、最近活动与处理记录采用紧凑行。详情通过只读浮窗查看和复制，支持 Esc 关闭及焦点返回；不在列表内展开长正文。图片下载成功仅显示“已下载，尚未确认模型读取”，不会把下载回执当作模型看图证明。连续相同错误在一分钟窗口内合并计数。

会话页提供自动维护状态和只读详情，无手工清理卡片。普通运行及已结束记录默认保留 7 天；临时记录到期后台回收。单类记录超过一万条或数据库达到七成容量时，提前回收一小时前可安全删除的记录。未知任务、用量和会话历史继续保留。

简短操作说明使用按钮旁的问号提示：悬停、键盘聚焦或点击可打开小浮窗，移开、点击外部或按 Esc 关闭。概览和连接页的启动检查说明不再占用折叠卡片；应用按钮与超时开关使用同一轻量提示。长记录继续使用只读详情窗口。已有的人设和方案不在编辑表单展示只读内部标识；保存、应用与简短状态在卡片底部横向排列，窄屏换行。

## 配置界面密度

正式控制台采用紧凑配置布局：正文字号 12px，辅助信息 11px，控件高 27px，短字段横向排列，面板间距 8px。浅灰蓝页面与微着色面板区分内容层级。人设身份与表达风格在宽屏并排编辑，唤醒参数、上下文容量、引用管理等低频内容通过二级窗口维护。编辑窗口关闭后保留草稿，保存仍使用各配置自己的操作。

最近活动与处理日志使用约 20px 行高和交错浅色背景，详情按钮保持行内；异常和未知结果继续直接显示。删除使用直接按钮和确认窗口。窄屏导航可点击外侧空白、按 Esc、点击关闭按钮或选择页面收回；桌面侧栏保持正常布局。

侧栏宽度为 192px，顶部显示“配置工作台”。导航采用图标、完整任务名称与序号，不再显示“工作空间”分组标题；收起时仅保留图标。

模型服务表单按编辑区域实际宽度切换一列或两列，上下行统一列宽。标签保持单行；可选说明放入提示，启用开关位于卡片标题栏，清除密钥的开关靠近文字。
