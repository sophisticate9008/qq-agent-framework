# 工作台使用说明

工作台用于配置、查看运行状态和维护记录。日常聊天、模型提问、工具确认和独立工作请求在所属 QQ 会话进行。需要同意或拒绝工具操作时，由实际配置的主人在 QQ 内回复。

## 登录与页面导航

打开启动时显示的管理地址。在“连接你的工作台”中，按页面提示的本机文件位置复制管理员令牌，进入工作台。令牌只用于建立本浏览器的访问会话；页面使用 HttpOnly cookie 保持登录，默认绝对有效期为 7 天。点击右上角“断开连接”会撤销当前访问会话。

侧栏按任务组织：

| 入口 | 主要内容 |
| --- | --- |
| 概览 | 运行摘要、“开始聊天”配置步骤和最近 100 条进程内活动 |
| 会话 | QQ 会话绑定、队列、逐会话诊断、媒体与引用观测、QQ 互动和执行日志 |
| 用量 | Token、费用、走势、逐轮记录、计价、导出、归档与清理 |
| 伙伴 → 人设 | 身份定义、表达风格和角色参考图 |
| 伙伴 → 聊天方案 | 模型、人设关联、方案指令、DSH 应用、助手目标和独立工作记录 |
| 模型 | 模型提供方、连接凭据和可选模型目录 |
| 功能 | 唤醒与续聊、回复方式、提醒、记忆、工具通道和功能包配置 |
| 连接 | QQ、DSH、聊天运行与应用详情，以及高级账号管理 |
| 安全 | 主人与白名单、独立工具授权、回复与超时、管理端和程序出站网关设置 |

顶部“搜索工作台”可搜索页面、分组和字段名称。“本页目录”用于跳转当前页的分组。搜索会打开目标所在的折叠区或标签；禁用、尚未配置或缺少前置条件的字段仍可被找到，页面会说明不能聚焦的原因。搜索和导航不会保存配置。

右上角可选择跟随系统、日间或夜间模式。窄屏通过“切换侧栏”打开导航；长表格在各自区域滚动，页内目录也可单独展开。

连接页分别显示 WebSocket 当前状态和最近诊断。入站事件处理失败或超时会保留为“最近入站处理异常”，连接仍正常时继续显示“WebSocket 已连接”；只有当前鉴权失败才提示核对 WebSocket 专用密钥。接收与丢弃计数包含协议事件，不能直接当作聊天消息数量。聊天停止时仍可明确重新连接或断开。

## 第一次开始聊天

登录后，可从概览的“开始聊天”依次打开配置。每一步分别保存，最后明确应用。

1. **连接 QQ 与 DSH。** 在“连接”填写实际 QQ 接入所需的收发连接。普通本机 DSH 使用自动发现和本机鉴权；远程接入、手动地址和路径在高级设置中。保存收消息连接与聊天就绪是分别显示的状态。
2. **登记模型。** 在“模型”创建提供方，选择接口协议、填写所需凭据并登记模型。提供方名称和模型显示名称用于识别，API 模型 ID 用于实际请求。
3. **设置人设和聊天方案。** 在“伙伴 → 人设”填写并保存身份与表达风格。在“伙伴 → 聊天方案”选择模型和关联人设，填写方案指令；“保存聊天方案”用于只保存草稿，“更新聊天”会保存当前方案、选择启用并应用。
4. **设置主人与白名单。** 在“安全”明确主人账号及允许参与的群聊、私聊。功能参与范围、输出选项和人设内容各自保存，权限仍由访问控制核验。
5. **核对并应用。** 方案页点击“更新聊天”，其他应用入口按页面提示操作。普通流程会自动识别本机配置层与所选模型的元数据，按实际需要停止聊天、准备并应用配置、核对会话衔接，再启动聊天。

概览的步骤只表示已核对相应配置。启动前请查看缺失条件，启动后在真实 QQ 会话中核对消息结果；“已保存”本身不表示模型已经运行。

## 草稿、保存和应用

| 状态 | 含义与操作 |
| --- | --- |
| 未保存 | 编辑仍是草稿；当前方案可用“更新聊天”一并保存和应用，其他配置分别保存或撤销 |
| 已保存待应用 | 配置已经保存；当前运行会话可能仍使用原配置 |
| 后台处理中 | 已确认的应用操作由服务端继续处理；页面只观察阶段 |
| 当前启用方案运行中 | 当前会话已报告匹配的运行配置；具体消息结果仍看实际记录 |
| 结果待核对／未知 | 保留原操作标识与证据，先读取或核对，不重复提交 |

普通配置草稿在当前工作台内存中保留：切页、折叠和返回编辑不会隐式保存。模型提供方的密码和密钥输入不随普通草稿保留，离开编辑页后需要重新填写。完整刷新或关闭浏览器后，未保存草稿不保证恢复；主动退出会清除草稿。

读取失败时，页面会标记不可用或待核对，并保留可用的上次结果、草稿。发生版本冲突或写入结果未知时，按页面入口读取已保存内容；需要继续编辑的表单，会要求明确核对后再允许新的保存。读取成功不代表上次外部应用已经成功。

方案页上方与下方的“更新聊天”使用同一流程：保存当前编辑的方案并将其选择为启用方案，然后只创建一个应用操作。已经保存且已启用的方案不重复保存。它不会代为保存其他人设、提供方、助手或手动 DSH 设置的草稿；未保存的手动 DSH 设置需要先处理。方案保存冲突或结果未知时，应用不会继续提交。

DSH 的普通应用使用持久操作标识。处理较慢时显示当前阶段，只查询同一个操作，不重复提交。关闭页面不会取消服务端已经确认的应用，回到同一账号可继续读取原操作。服务明确拒绝受理的请求显示拒绝原因，不当作已经发生的未知应用。

“核对并继续更新”作用于原操作。若写入已发生但尚未确认加载，后台先核验原配置版本、实际 DSH 预设与来源；证据齐全后沿原操作继续会话衔接和启动，跳过已经执行的停止、准备与应用。其他阶段仍按各自证据核对；不足时保留阻碍，不自动重放。

手动 DSH 详情中的恢复入口另有证据要求。只有后台核验实际应用记录后，页面才允许明确开始新的管理操作；任意一次成功刷新都不能代替应用核验。

## 人设、模型与独立助手

人设保存身份和表达风格，聊天方案保存模型选择、指令和群聊／私聊上下文策略。新建人设和方案会自动生成稳定标识；高级设置允许创建前调整标识，创建后固定。

模型选择可在方案内就地新建提供方或模型，保存模型目录后返回原选择位置。方案的其他草稿会保留，随后通过“保存聊天方案”或“更新聊天”明确提交。思考强度只允许选择实际模型声明的支持值；旧值尚未核验时仍显示在下拉框中并标记待确认。读取失败会说明已知原因，可点击“重新读取支持情况”恢复查询，不会自动改档。

模型提供真实容量信息时，新建方案尚未手改的默认容量可采用建议值。已有方案可点击“使用模型建议容量”，先查看模型窗口、最大输出与预留空间，再明确采用。自定义容量不会被自动覆盖；容量变化仍需通过应用及会话衔接核验。

删除人设、方案、提供方或模型时，先查看引用使用者。按页面操作更换目标或解除引用，再明确确认删除。仅聊天模式会保留助手目标，因此保留的助手目标也可能阻止删除模型。与角色参考图存在绑定的人设需先解除绑定。

“聊天模式”区分“仅聊天”和“聊天＋助手”。独立助手的提供方、模型和思考等级单独保存，再通过“独立助手目标应用”准备、核验和应用。可用性及缺失条件以实际状态为准。

“独立工作记录”可筛选、查看结果、迟到结果和回父会话的消息／文件回执。实际发起、追加、停止和恢复工作在所属 QQ 会话进行。工作中的模型问题和工具确认也回到 QQ，不需要守着网页。

## 功能、工具和内容

### 唤醒、回复与权限

“唤醒与续聊”配置昵称、@、引用机器人、同人续聊期限，以及群聊／私聊参与范围。排除项优先；这些选项不增加白名单或工具权限。

“回复方式”控制分气泡、媒体输出和长文转发等行为。合并转发还需要独立的“合并转发权限”；旧次数模式有单独的转发次数，白名单模式需明确选择允许转发的会话。开启长文转发选项不会生成发送权限。

框架工具在“安全 → 框架工具授权”按能力和所属 QQ 会话明确授权，可限定次数、有效期或明确不限。撤销保留已消耗记录，重启不会补回额度。页面显示的功能开关、工具目录和助手模式均不自动授予这些权限。

“功能”中的“聊天工具”标签显示工具与真实工具通道；“功能设置”标签显示贡献配置、实际功能清单和默认折叠的“可信扩展装配摘要”。声明、实际安装、运行就绪和会话授权分别核对。摘要可查看选定的本地扩展、安装记录和入口指纹；本地扩展在宿主进程中运行，不受沙箱隔离。

功能包贡献的设置按当前服务提供的字段编辑，显示需要实时应用还是重启。版本迁移有独立确认入口；保存包配置不会授予工具权限。

### 提醒、记忆与角色参考图

提醒可设置目标会话、正文、时区及一次、延时、每日或每周规则。新草稿默认停用；确认启用且调度服务运行后，才按规则和实际发送条件处理。页面可查看下一次执行、历史结果、停用和取消。未知发送结果会保留隔离状态，不自动补发；取消未来规则也不会撤回已经发生的发送。

“记忆与偏好管理”可按范围查看来源、有效期和修改记录，并手工创建、纠正、撤销或清理。全局资料是管理员明确共享的内容；群聊和用户资料保留所属范围。模型提出的资料保持待确认状态，只能通过所属 QQ 会话的实际主人回复确认；工作台没有模型提议确认按钮。

人设页的“角色参考图”使用独立素材库。上传 PNG、JPEG、WebP 或 GIF，大小以页面限制为准；上传与绑定分别确认。选择已有素材上传可新增不可变版本，已有绑定仍指向原版本，需明确更换。预览和版本回看只读；被绑定的素材先解除引用后才能删除。

参考图说明作为素材资料保存，不写入人设身份。模型需要通过获准的角色参考图读取工具取得当前绑定版本，图片是否已读取以实际结果为准。

## 会话状态与恢复

在“会话”选择目标 QQ 会话，查看绑定、排队数量、处理中或隔离状态、期限和已读取的分页范围。筛选只作用于当前已加载记录；页面提示仍有后续时，可继续加载。

“检查此会话为何没有回复”按目标会话读取运行、白名单、唤醒、执行隔离和发送证据，给出具体下一步。部分历史、未知和不可用会明确标记。上下文容量只在实际可确认的会话中显示，缺少模型信息时不补造数值。

媒体与引用区域区分登记记录、曾读取内容或字节、当前读取链和最近一次读取结果。历史曾读标记不覆盖当前失败；图片理解还取决于实际模型能力，语音需要实际转写服务。引用只有在同会话读取成功后才显示已核对；没有观测记录时保留未确认。

“待处理提问与工具审批”只读显示 QQ 所属会话、问题或脱敏理由、有效期限和状态。处理请回到 QQ；过期、拒绝或未知状态不会变成网页批准。

### 执行结果核对

在“任务执行日志”打开目标记录，查看“执行结果与上下文恢复”：

1. 先“读取原执行与恢复结果”，检查当前状态和具体阻碍。
2. 明确确认后可“核对执行结果”。此操作只观察 SDK 持久证据，不重放旧请求或迟到输出。
3. 需要保留上下文恢复且条件允许时，先“预览保留上下文恢复”，核对原会话与计划，再“确认创建新的会话地址”。
4. 创建结果未知时，读取或“核对原恢复请求”，始终沿原恢复计划版本检查，不再创建另一份会话。
5. 按页面提示在“连接”明确重启聊天，建立核验后的会话关联。

证据不足会继续阻断。管理核对、恢复计划和 QQ 工具确认是不同操作，不能相互代替。

“重新开始对话”另用于明确放弃当前绑定：先停止聊天并刷新会话列表，确认选中的绑定后操作。它保留旧历史、用量和执行记录，下次聊天建立新上下文，不会停止外部任务。绑定变化或结果未知时，按钮冻结，先关闭并刷新核对。

## 多账号工作空间

在“连接”展开“高级：独立账号与原账号采用”，查看当前工作空间、创建独立账号并选择“管理此账号”。账号需要实际协议身份核验；创建和选择均不会自动启动、停止或应用。

选中账号后，聊天配置、权限、会话和操作证据属于该账号，顶部显示账号名称。切换会隔离读取、草稿和未决操作，不能把原账号的未知写入提交到另一个账号。管理端监听、登录和程序出站网关仍是全局设置。

账号选择保存在当前页面内存中，普通刷新后需重新选择其他独立账号。原单账号已被明确采用时，读取账号目录会自动选择该采用账号；已有有效选择会保留。

原单账号数据先隔离保留。采用前停止原聊天，填写并核对协议账号，预览配置与持久库，再明确确认。采用成功后旧聊天入口停用，页面切到采用账号。结果未知时只核对原采用目标，不再次发起采用；此操作不恢复未知执行或补发旧消息。

## 用量、导出与账本维护

用量页可查看总量、趋势、会话和逐轮记录。“详细数值”切换数值显示，不改变数据。统计详情、会话记录、轮次记录和调用记录可分别展开；表格在卡片内滚动。图表悬浮查看桶详情，也可从“时间桶明细”选择并固定，移动端提示框保持在可见视口内。

费用是按有效价目表估算或已报告的金额，不能替代服务商实际账单。未知值保留未知；“已记录费用”可能只是已知金额小计。不同币种分开显示，覆盖不完整时不能将小计当作完整总账。

内置参考价目表可查看；人工单价覆盖在高级区编辑，仅影响后续入账估算，历史记录保留原价格与金额。

“归档与清理用量记录”提供明确范围操作：

1. 选择开始时间、结束时间（不含），按需填写会话、提供方和模型筛选。
2. 可直接导出当前记录或归档 JSON；页面核验导出校验值，并提示分页或截断。
3. 点击“预览归档”或“预览清理”，核对精确记录、保护的未知记录、范围和阻碍。
4. 明确确认本批操作。每批最多 60 条，有下一批时重新预览并确认。

归档保全明细并从当前账本移出；清理永久删除所选用量明细，保留防止迟到重复入账所需的最小记录。两者均不删除会话、执行、独立工作或发送回执。

断网或回执丢失时，用“读取原操作结果”检查原操作，未知结果不重新提交。刷新或关闭页面后，可展开“查找已记录的账本操作”，按范围与操作标识找到原记录再读取详情。该列表按存储位置分页，每批最多 20 项，不自动确认或继续写入；失效预览和已完成结果分别显示。

## 管理服务与独立网关

“安全”中的“回复与超时”控制主聊天处理期限、超时提醒和停止策略。“程序出站网关：期限与发送额度（高级）”控制程序直接调用独立出站接口时的限制，分别保存和应用。

“管理端监听”更改工作台的地址与端口，保存后需明确“应用并重启”，再按新地址重新连接。程序出站网关的技术身份、版本与协议放在独立高级区，日常聊天使用已选择的人设和方案。

概览分别显示工作台、QQ、聊天处理和模型执行的实际状态。工作台可访问或协议已连接，都只是相应链路的状态；具体故障请优先使用目标会话诊断及实际执行、发送记录核对。
