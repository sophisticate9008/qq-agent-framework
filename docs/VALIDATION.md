分批真实场景确认：主人及普通成员、群聊与私聊、连续聊天、引用、当前会话历史和群成员查询、主人好友/群目录查询、非主人敏感动作拒绝、白名单即时撤销与恢复、QQ 自带表情及收藏表情图片、图片实际识别、文本文件读取、转发文本与转发内图片读取、群聊及私聊合并转发、群聊及私聊戳一戳、主人撤回机器人消息、群上传通知和错误目标通知不唤醒。早期场景另核验过旧媒体开关不影响文字、引用、@ 和 QQ 自带表情；之后按需求移除了该开关，当前发送使用协议能力与会话资源规则。

协议捕获核对了真实附件字节：群文件和私聊文件原样回传均为 62 字节，语音回传为 8044 字节，与入站素材逐字节和 SHA-256 一致。图片以实际模型回复的左右颜色核验，不能只以登记成功或文件类型代替识别。语音素材是测试音调，验证仅覆盖收发；未配置的语音转写仍明确不可用。

真实 NapCat 仅做只读检查：群、好友、成员、历史、单条消息、收藏表情与图片下载均取得实际响应；另验证私聊机器人消息归属必须有同会话发送证据。真实 QQ 的发送、戳一戳和撤回没有在本轮试发，不能把本地协议捕获描述成真实 QQ 已送达。

“最近活动”已实际通过浏览器核对：全部、QQ、模拟筛选，桌面与移动端，详情以及虚拟列表滚动。多轮记录按各自快照对照真实入站/通知及本地出站捕获；纯媒体显示类型摘要，模拟发送标记为本地捕获。运行中新增记录按读取时刻比较，不把不同采样时刻的条数差误报为丢失。私有证据位于被忽略的 `runtime/simulations/`、`runtime/ops-backups/` 和 `runtime/simulation-activity-review/`，不提交账号、会话原文或凭据。

## 2026-10-27：Markdown 图片与视频抽样

Markdown 图片采用内置本机排版服务。真实模型的排版请求最终产生 PNG，协议捕获取得实际图片字节；人工查看图片确认中文、标题、列表、引用、表格、代码高亮和公式正常显示。另查看长文分页图，修正了分页处文字被截断的问题。群聊与私聊纯文本长文分别进入合并转发，未变成 Markdown 附件。

视频使用六秒红、蓝、绿三段画面及音轨的实际 MP4。完整模拟链路中，关闭、开启、再次关闭的累计素材读取次数为 0、1、1；开启时普通白名单成员可发起观察。DSH 工具结果包含六个真正的图像附件，模型正确报告颜色顺序、抽样时间及只检测到音轨而未听取或转写。视频开关通过真实包配置 CAS 修改；收到视频本身不自动触发下载。

独立 FFmpeg 验证覆盖 MP4、Matroska、非零起始时间和带音轨视频；时间戳取实际解码结果，临时文件在结束后清理。首次完整启动曾因配置字段标识格式错误失败，修正后重新完成链路，失败记录保留。上述观察只证明抽样画面识别，不等于连续视频理解或语音转写，也不是向真实 QQ 发出的测试。

本轮还修正了独立助手结束后用量漏采：DSH 会先移除助手实例，再通知任务结束，采集改为在实例释放事件携带的准确子会话对象上读取，并核验父子身份。修复后的真实联合场景自动记录 10 条聊天步骤和 10 条 GPT 助手步骤，助手步骤与实际子会话事件一致，自动进入模拟账本及主账本，不依赖手工补记。
