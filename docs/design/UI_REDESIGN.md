# 配置工作台：布局与密度设计草案

状态：完整功能设计稿 v3 已获用户批准，正式页面按此稿实施。静态稿已渲染作为九页布局参考；保留真实配置与运行接口，按卡片组合、内容位置和分栏比例接入。

入口：[完整功能设计稿 v3](ui-full-preview.html)；[范围与查看说明](full-console/README.md)。前两版设计与实施记录保留在下文，后续以 v3 审核结果为准。

## 设计判断

参考图的价值在于同一实体的信息聚合：名称与状态在首行，数量与时间作为次级信息，运行摘要放浅色条，操作放底部同一行。它不是把所有内容缩成小字，也不是给每个字段包一张白卡。

现有实现的共性问题：

- `Section` 将标题、说明、正文、底栏用在过多不同场景；嵌套后重复边框与留白。
- `Field` 普遍将标签、输入、说明纵向排列；数值、开关也经常占满整行。
- 字号分散，线上源码混用 10、11、12、12.8、13、14 等尺寸；按钮高度和主次样式不一致。
- 状态、说明、版本和标识与真正的编辑内容竞争注意力。
- 折叠承载了四类不同用途：普通设置、低频设置、只读记录和删除确认，交互意图不清楚。
- 概览、连接和功能重复解释内部装配；旧授权/旧限制组件仍留在源码，需区分已脱离页面的代码和真实可见入口。

## 六种布局，不再用一种卡片覆盖全部场景

| 场景 | 布局 | 规则 |
| --- | --- | --- |
| 连接、账号、模型服务 | 实体摘要 | 名称＋状态；元信息同行；浅色摘要条；操作同行 |
| 日常设置 | 紧凑表单分区 | 以分区标题和细分隔线组织，不再层层套卡；短字段同行 |
| 人设、提示词 | 内容编辑 | 全宽长文本；名称、昵称、模型等短字段靠上；低频参数打开编辑弹窗 |
| 会话、模型清单、日志 | 表格或紧凑列表 | 名称、状态、时间、操作同一行；长内容在详情窗口中查看 |
| 低频设置 | 二级编辑窗口 | 有明确标题、保存/取消语义；关闭不丢未保存草稿，不隐式应用 |
| 删除、解绑 | 确认窗口 | 入口直接是按钮；窗口显示具体对象、实际影响与确认操作 |

二级窗口用于减少主页面负担，不把每个普通开关或短字段都变成弹窗。只读详情和编辑窗口采用不同操作语义，不在只读窗口放保存按钮。

## 信息层级

1. 常驻：用户命名、当前选择、可操作状态、必填字段、主要动作。
2. 同行辅助：模型名、数量、最近更新时间；不独立撑出一排。
3. 按需说明：字段用途放悬浮/点击提示；低频参数放编辑窗口。
4. 技术详情：内部 ID、revision、原因码、通道和装配记录只在详情窗口出现。
5. 移除：无条件成立的状态、反复说明“已声明/已安装”、页面上重复出现的流程教程和失效入口。

错误、未确认结果、阻止操作的原因必须在当前操作附近可见。不能为了简洁把失败藏进详情，或显示为成功。

## 密度与视觉规范

- 默认紧凑档：正文/字段/输入 12px，辅助信息 11px，分区标题 13px，页面标题 18px；长文本行高 1.6，普通信息约 1.45。上一稿的 15px 正文被用户明确指出过大，不再作为本轮目标。
- 预览提供极紧凑 11px / 24px 控件、紧凑 12px / 27px 控件、稍宽 13px / 30px 控件三档，便于比较整体显示比例；通过字号与布局变量切换，不使用整体缩放图片。
- 默认控件高 27px，表单行约 30px，列表操作 23–24px。桌面以配置工具的密度为目标；窄屏按列换行，保留可聚焦状态与明确操作名称。
- 同组字段纵向间距 6px、横向 14px，分区间距 8px，面板内边距 10px；标签不再默认额外占整行。
- 数值框按内容限宽；地址和密钥可伸展；短字段在桌面以 2–3 列排列。窄屏自然换行。
- 页面浅灰蓝 `#f2f4fa`，面板微着色 `#fafbfe`，摘要条 `#edf1f8`，边框 `#dfe5ef`，主文字 `#243047`，辅助文字 `#65738a`，主要操作使用低饱和紫色。
- 编辑表面使用接近白色的背景，状态与辅助区域用浅色区分；减少阴影与重复描边。暗色模式保留同等层级，不硬编码为纯白。
- 同组按钮统一高度；保存/应用为主操作，刷新/查看为次操作，删除用文字或图标危险色。
- 每个操作区突出一个主要动作；保存与应用有不同语义时必须保留区别，不擅自合并业务。

## 过时 UI 审计范围

- 已脱离页面的旧工具组合、工具授权、次数/期限限制界面：核对引用后移除旧 UI 和专属失效文案，不删除持久数据。
- “会话衔接与状态核对”、手动部署参数：区分必要恢复能力和重复入口，保留恢复能力但降低常态占用。
- “去连接与安全应用”、旧页面名称、旧预算/额度搜索别名：同步导航、搜索和说明。
- “框架功能包与工具通道”、声明/安装计数：不作为普通用户的主要功能卡片。
- 删除操作不再用折叠承载，不把确认窗口再套进编辑窗口。

## 实施顺序与验收方式

先完成代表性实体摘要、配置表单、列表与确认窗口，再把同类页面按同一规范替换。按组件/文件划分子代理任务，主控统一审阅信息层级与交互。

本轮不运行自动化测试。设计稿先用于核对布局；实现后仅完成必要构建与启动状态核对，实际操作由用户实机验证。设计稿中的演示数据不接入真实服务。

## 交互草案 v2 的场景覆盖

打开 [高密度交互预览](ui-density-preview.html)，左侧切换场景，右上角切换密度。上一稿保存在 [v1 对照](ui-density-preview-v1.html)。

1. 连接与概览：3 个实体摘要、10 行活动、紧凑方案设置、异常提示条。
2. 密集配置：三列表单、多开关组、白名单标签、同栏维护动作。
3. 人设编辑：8 项选择目录、短字段同行、身份/风格双栏编辑。
4. 模型服务：提供方切换、连接参数、12 行模型表格、搜索、模型编辑窗口。
5. 会话与日志：14 行会话、文字与状态组合筛选、12 行日志、侧边只读详情。
6. 用量统计：4 项数字汇总、12 个时间点走势、模型费用表与8行会话用量。
7. 功能与扩展：6 项开关矩阵、媒体状态行、8 个扩展条目。
8. 布局与状态：横向标签表单、属性列表、内联摘要三种对照；连接失败、未知结果、字段校验、草稿、禁用、加载、空列表与浮动提示。

窗口包含连接编辑、模型登记、低频参数、右侧只读详情和直接删除确认。示例按钮不会读取或写入真实服务；没有部署，也不运行自动化测试。

### 已确认的活动日志微调

最近活动与处理日志采用相同的控制台式紧凑行：18px 行高、上下各 1px 内边距，详情按钮保持行内 18px 高，避免按钮撑大整行。相邻行交替使用浅灰蓝底色，悬浮/聚焦时加深；异常保留文字颜色提示。活动面板按内容收缩，避免因旁边配置面板较高而留下底部空白。其他布局与字号保持已认可版本。

## 正式版落地

已按 v2 将公共密度、配置横排、二级编辑与只读详情、日志交错行应用到正式页面。窄屏侧栏补充外侧点击关闭、Esc、关闭按钮和选择页面后收回。预览中的演示数量与内容不填充到正式页面，正式页面只显示实际读取的数据。
