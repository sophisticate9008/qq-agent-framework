# 完整功能离线设计稿 v3

打开 [`../ui-full-preview.html`](../ui-full-preview.html) 查看合成的单文件设计稿；本目录 `index.html` 是同一设计的分文件入口。

本稿只用于审核布局与交互，不接入真实 API，不读取账号和凭据，不修改正式业务，不构建或部署控制台。文案中的名称、数量、时间、费用和会话内容均为演示数据。源 HTML 使用 `connect-src 'none'` 限制网络请求。

## 查看顺序

1. **连接与概览**：三张实体摘要卡，活动和当前聊天左右组合；短回复分条、长文合并转发、发送已登记媒体在当前聊天卡片直接调整，独立保存；底部集中显示需要关注的事项。
2. **连接设置**：QQ、DSH 与聊天运行的摘要和操作；参数集中在编辑窗口。
3. **人设编辑 / 聊天方案 / 模型服务**：目录与编辑区左右组合，短字段同行，长文本和模型列表有独立空间。
4. **会话与日志 / 用量统计**：筛选、表格和记录页签，完整内容在只读侧窗，危险操作单独确认。用量沿用现有时间轴、网格和细柱样式；DeepSeek 高峰橙色、低谷绿色、混合蓝色，悬浮看数值、点击看时段明细。峰谷与费用均为演示数据，不代表当前提供方价格时刻表。
5. **功能与扩展 / 访问与设置**：真实已有的回复配置、工具接入、主人白名单与处理参数。

可点击导航、页签、设置、详情和确认按钮；部分选择和表单可在本地模拟修改。弹窗关闭时保留演示草稿。顶部可切换常态、加载、失败、未知结果的布局示例。手机宽度下导航可点击外部空白、选择页面或按 Esc 收回。

## 已批准实施

仓库检查通过 `scripts/check.ts` 中的 `authoredJavaScriptDirectories` 配置目录例外：`docs/design/full-console/` 及其子目录允许使用 JavaScript，便于直接打开离线预览，无需构建；新增设计脚本无需逐文件登记。文件大小、凭据格式与符号链接检查仍保留，正式源码继续使用 TypeScript。

用户已明确批准实施。九页静态参考已渲染，正式界面按相同卡片组合、内容位置、比例、列宽和视觉层级接入真实数据。此稿的演示按钮不会取代正式页面原有的保存版本核对、权限、未知结果保护与恢复流程。

设计阶段未运行自动化测试或重启服务。实施阶段仅运行必要构建与页面渲染，业务操作由用户实机验证。
