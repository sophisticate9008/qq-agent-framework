# 扩展接入示例

示例展示如何组合框架服务。克隆仓库或安装 SDK 不会自动启用示例；需要在可信 bootstrap 中明确装配，并提供各自依赖。

| 示例 | 展示内容 | 外部依赖 |
| --- | --- | --- |
| [可重载服务](reloadable-plugin/README.md) | 服务、工具、日程和工作流热重载 | 框架插件宿主；结果仅存本地 |
| [空间生活日记](qzone-diary/README.md) | 持久会话、日程、图像审查、协议发布和任务详情 | 自备生图服务、角色素材、写作与视觉模型、支持图文发布的协议端 |

示例业务源码可公开复用，安装者的账号、供应商凭据、角色素材和运行数据保存在私有目录。框架发布说明介绍通用能力，示例业务单独说明。
