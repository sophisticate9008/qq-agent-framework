# 空间生活日记：组合服务示例

这是业务扩展参考实现，用来展示如何用框架的持久会话、调度、媒体、协议及热重载服务完成一个工作流。它不是框架内置功能，不随安装自动启用，也不包含现成可用的生图服务或角色参考图。

完整源码位于 [plugins/qzone-diary](../../plugins/qzone-diary/README.md)，保留这个导入路径供已经装配的实例使用；这里提供统一的示例入口，不复制第二套实现。源码随 GitHub 源码包分发，不包含在 SDK 或 DSH 桥接插件的 npm 安装包里。

## 需要自己提供什么

| 依赖 | 接入方式 |
| --- | --- |
| 框架 1.3.0+ | 提供 `plugin-runtime` 和任务详情登记能力 |
| 生图扩展 | 发布 `IMAGE_GENERATION_SERVICE_CONTRACT`，返回实际图片字节；将该包的标识传给 `imagePackageId` |
| 自身形象素材 | 由生图扩展在内部读取并组合；日记插件不附带任何私人素材 |
| 模型 | 已配置的写作模型和声明支持图片输入的视觉模型 |
| 协议端 | 实际支持空间图文发布；本机共享目录或自定义媒体适配器 |
| 私有配置与存储 | `configuration()`、持久存储、图片产物目录；启停写入可通过 `setEnabled` 注入 |

生图接口是通用契约，安装者可接入自己的实现，不要求使用本机的私人生图服务。密钥保留在对应提供方或服务配置中。

## 装配与管理

在现有可信 bootstrap 中导入 `createQzoneDiaryPackage`，传入上述依赖，和生图包一起加入 `packages`。具体参数、配置类型和完整业务流程见 [插件接入说明](../../plugins/qzone-diary/README.md#接入)。不提供伪造供应商和素材路径的“开箱即运行”配置。

初次接入可配置 `enabled: true, publish: false`：仍会真实调用模型、生图和视觉审查并产生相应用量，只停在审查后的预览。确认实际配置后再显式设置 `publish: true` 开启真实发布。关闭整个业务使用 `enabled: false`。

装配后，任务显示在控制台「任务与日程」；插件通过 `registerDetailsProvider` 提供业务阶段、会话、文案、缩略图和跳过处理。页面和通用调度器均不依赖空间日记业务。

学习最小调度与详情接入可先看 [持久任务服务](../../docs/TRIGGERS.md)，学习可替换行为可看 [热重载示例](../reloadable-plugin/README.md)。
