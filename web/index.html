首次连接与初始化
  1. 在管理机设置两个私有配置路径后运行 node scripts/configure-gateway-admin.ts --config "$PRIVATE_ADMIN_CONFIG" --gateway-config "$PRIVATE_GATEWAY_CONFIG"。工具生成独立管理 Token 文件，不把 Token 打印到终端。
  2. 初始化时可另加 --host、--port 和 --token-file；已有配置直接编辑后重载，工具不会覆盖。
  3. 监听地址和端口写入私有 config；默认仅回环。开放局域网监听时，浏览器应访问管理机的实际 IP，而不是 0.0.0.0。
  4. 管理 Token 来自管理员自己的 tokenFile。粘贴后仅驻留本页内存，不会写入 URL、localStorage 或 sessionStorage。
  5. 纯 HTTP 仅适合可信局域网，不能直接暴露公网。此页面不能代替后台鉴权、网络隔离和安全部署。

完整配置与排障说明：docs/GATEWAY_ADMIN.md
